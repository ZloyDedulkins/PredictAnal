# PredictAnal

Веб-приложение для оценки качества прогнозных моделей по временному ряду из Excel.

## Почему по GitHub-ссылке может показываться только текст

Ссылка на репозиторий GitHub открывает README (текст), а не запускает Flask-приложение.
Чтобы открыть сайт, нужен URL запущенного сервера (Codespaces port forwarding / Render / Railway / VPS).

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

Открыть в браузере: `http://localhost:8000`

## Возможности

- Загрузка Excel (`.xlsx/.xls`) с колонками `период`, `показатель`.
- Автоматическое разделение данных: `train=95%`, `test=5%`.
- Сравнение моделей:
  - Moving Average (baseline)
  - Holt-Winters
  - Prophet (если установлен)
- Расчет метрик MAE и RMSE.
- Выбор лучшей модели по RMSE.
- График по **всему периоду** и прогноз на **следующий месяц**.
